## License boundaries

| Classification | What was reviewed |
| --- | --- |
| [Open-source](catalog.md#open-source-software) | The named distribution or component has an OSI-approved software license. License evidence and scope appear on each entry. |
| [Source-available](catalog.md#source-available-software) | Source can be inspected under terms that restrict some uses. Review the actual restrictions before deploying. |
| [Mixed-license](catalog.md#mixed-license-software) | An open-source edition or component shares a project with separately restricted code. The entry identifies the boundary. |
| [Proprietary](catalog.md#proprietary-software) | The entry describes a hosted or commercial product offered under vendor terms. |

Cost labels apply to the reviewed edition and may exclude hosting, data, model access, or support. Difficulty reflects the work required to apply the resource. Recent repository activity is evidence of a public push within 180 days of editorial review. It carries no support guarantee. Proprietary offerings and reference materials receive different status labels based on what the publisher exposes.

## Submit an entry

Use the **Resource submission** or **Open-source project submission** form in the repository. Read the [review process](../resource-review.md) for evidence and acceptance criteria. Useful in Practice’s own projects and newsletter identify their publisher on their entries.
